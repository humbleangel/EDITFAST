## What to build

Centralised module that reads Fast Apply API configuration from environment variables, with the same defaults as the original plugin.

File: `src/config.ts`

Exports:
- `FAST_APPLY_API_KEY: string` — reads `process.env.FAST_APPLY_API_KEY` or returns `"optional-api-key"` default
- `FAST_APPLY_URL: string` — reads `process.env.FAST_APPLY_URL` or returns `"http://localhost:1234/v1"`, then strips trailing `/v1` (and `/v1/`) so the result is the host root
- `FAST_APPLY_MODEL: string` — reads `process.env.FAST_APPLY_MODEL` or returns `"fastapply-1.5b"`

The URL normalization: replace `/\/v1\/?$/` with `""` so that callers add `/v1/chat/completions` themselves.

Tests: `tests/config.test.ts` (override `process.env` in tests using `Bun.env` semantics)

## Acceptance criteria

- [ ] All three exports read from env when set
- [ ] All three exports use documented defaults when env is unset
- [ ] `FAST_APPLY_URL` strips `/v1` suffix
- [ ] `FAST_APPLY_URL` strips `/v1/` suffix (with trailing slash)
- [ ] Empty `process.env.FAST_APPLY_API_KEY` returns the default (not empty string)
- [ ] `bun test tests/config.test.ts` passes

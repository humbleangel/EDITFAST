## What to build

Whitespace-normalized fallback matcher that locates `needle` in `haystack` even when line endings or trailing whitespace differ.

File: `src/matching.ts` (extend)

Exports:
- `findNormalizedMatch(haystack: string, needle: string): number` — returns the byte offset of the first normalized match, or -1.

Logic:
1. Normalize both haystack and needle via `normalizeWhitespace` (T6)
2. Find `normalizedNeedle` in `normalizedHaystack` via `indexOf`
3. If -1, return -1
4. Otherwise, walk through the original `haystack` until reaching the corresponding character offset in `normalizedHaystack`, accounting for the original whitespace characters that the normalizer stripped (e.g. each `\r\n` collapses to one `\n`).

Reference algorithm: walk two pointers, on `\r\n` consume 2 chars in original but 1 in normalized.

Tests: extend `tests/matching.test.ts`

## Acceptance criteria

- [ ] Returns same offset as `findExactMatch` when strings are already normalized
- [ ] Finds match when haystack has `\r\n` but needle has `\n` (and vice versa)
- [ ] Finds match when haystack has trailing spaces on lines but needle doesn't
- [ ] Returns -1 when content actually differs beyond whitespace
- [ ] Offset returned points to the original (un-normalized) haystack position
- [ ] `bun test tests/matching.test.ts` passes

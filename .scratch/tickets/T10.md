## What to build

The HTTP client that calls an OpenAI-compatible `/v1/chat/completions` endpoint with the Fast Apply system + user prompts and parses the response.

File: `src/api.ts`

Exports:
- `FAST_APPLY_SYSTEM_PROMPT: string` — exact verbatim prompt instructing the model to merge code while preserving structure
- `FAST_APPLY_USER_PROMPT: string` — template prompt with `{original_code}` and `{update_snippet}` placeholders
- `callFastApply(originalCode: string, codeEdit: string): Promise<{ success: true; content: string } | { success: false; error: string }>` — performs the API call and returns a discriminated result

Logic for `callFastApply`:
1. If `FAST_APPLY_API_KEY` is empty, return `{ success: false, error: "FAST_APPLY_API_KEY not set..." }`
2. Escape both `originalCode` and `codeEdit` via `escapeXmlTags` (T3)
3. Build the user prompt by replacing `{original_code}` and `{update_snippet}`
4. POST to `${FAST_APPLY_URL}/v1/chat/completions` with `Authorization: Bearer ${FAST_APPLY_API_KEY}`, `model: FAST_APPLY_MODEL`, `messages: [system, user]`, `temperature: 0`
5. On non-2xx, return `{ success: false, error: "Fast Apply API error (<status>): <body>" }`
6. Extract `result.choices[0].message.content`; if missing, return error
7. Call `extractUpdatedCode(rawResponse)` (T5); on parse error, wrap as `{ success: false, error: "Failed to parse AI response: <msg>" }`
8. Return `{ success: true, content: mergedCode }`

Tests: `tests/api.test.ts` — mock global `fetch` with `bun:test`'s mock

## Acceptance criteria

- [ ] Missing API key returns `{ success: false, error: ... }` without making a fetch call
- [ ] Successful API response with `<updated-code>merged</updated-code>` returns `{ success: true, content: "merged" }`
- [ ] Non-2xx response returns error with status code and body
- [ ] Parse failure returns error wrapped with parser's message
- [ ] System and user prompts are exactly the same text as in the reference plugin
- [ ] Fetch is called with `POST` and the right headers and URL
- [ ] Code content is XML-escaped before being placed in the prompt
- [ ] `bun test tests/api.test.ts` passes

## What to build

Helpers for token counting estimation and formatted display. Used in the success result to communicate edit size.

File: `src/format.ts`

Exports:
- `estimateTokens(text: string): number` — `Math.ceil(text.length / 4)` (rough approximation)
- `formatTokenCount(tokens: number): string` — formats with "K" suffix when ≥1000; returns `"<num>K"` for `1000+`, `"<n>.<d>K"` for non-integer thousands, the raw integer for <1000. Strips trailing `.0` (e.g. `"10.0K"` → `"10K"`).

Logic for `formatTokenCount`:
```
if (tokens >= 1000) {
  const formatted = (tokens / 1000).toFixed(1)
  return formatted.replace(".0K", "K") + (formatted.endsWith(".0") || !formatted.includes(".") ? "" : "K")
  // Actually simpler: `${(tokens/1000).toFixed(1)}K` then strip `.0K`
}
return tokens.toString()
```

Test edge cases:
- 999 → `"999"`
- 1000 → `"1K"` (not `"1.0K"`)
- 1500 → `"1.5K"`
- 10000 → `"10K"`

Tests: `tests/format.test.ts`

## What to build

Pure XML escape and unescape utilities used to safely round-trip code through the Fast Apply API's XML-tagged prompt protocol.

File: `src/xml.ts`

Exports:
- `escapeXmlTags(text: string): string` — replaces `&`, `<`, `>`, `"`, `'` with their XML entity equivalents (`&`, `<`, `>`, `"`, `&apos;`)
- `unescapeXmlTags(text: string): string` — reverses the above (order: `<` `>` `"` `'` `&` so `&` is decoded last)

Reference implementation (from `tickernelz/opencode-fast-apply` `index.ts`):
- escape: replace `&` first, then `<`, `>`, `"`, `'`
- unescape: replace `<` `>` `"` `'` `&` in that order

Tests: `tests/xml.test.ts` using `bun:test`

## Acceptance criteria

- [ ] `escapeXmlTags("<div>&'\"</div>")` returns `<div>&&apos;"</div>`
- [ ] `unescapeXmlTags(escapeXmlTags(x)) === x` for arbitrary strings
- [ ] `unescapeXmlTags("&lt;")` returns `<` (decoded in correct order)
- [ ] Empty string returns empty string in both
- [ ] `bun test tests/xml.test.ts` passes

## What to build

Make `src/tool.ts` installable at `~/.config/opencode/tools/fast_apply_edit.ts` (the only path OpenCode actually loads custom tools from). Provide a one-line install command and a `bin/install.sh` script that does the copy.

File additions:
- `bin/install.sh` — bash script that copies `src/tool.ts` to `~/.config/opencode/tools/fast_apply_edit.ts`, creating the directory if needed. Prints success/failure.
- Update `package.json` with a `"install"` script: `bun run build && ./bin/install.sh` (where `build` is a simple `bun build src/tool.ts --outfile dist/tool.js` or just copy step)
- `README.md` section explaining the install command

The file MUST end up at exactly `~/.config/opencode/tools/fast_apply_edit.ts` because:
1. OpenCode scans `{tool,tools}/*.{js,ts}` (verified in `packages/opencode/src/tool/registry.ts:174`)
2. The filename without extension becomes the tool name → `fast_apply_edit`

## Acceptance criteria

- [ ] `bin/install.sh` copies `src/tool.ts` to `~/.config/opencode/tools/fast_apply_edit.ts`
- [ ] Creates `~/.config/opencode/tools/` if missing
- [ ] `bun run install` (or `npm run install`) invokes the script
- [ ] After running, the file exists at the target path
- [ ] Running `opencode` (or `opencode debug tools`) shows `fast_apply_edit` in the tool list

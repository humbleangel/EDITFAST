## What to build

Exact string matcher that finds the byte offset of `needle` in `haystack`, used as the first attempt in the file patching step.

File: `src/matching.ts` (extend, alongside T6)

Exports:
- `findExactMatch(haystack: string, needle: string): number` — returns `haystack.indexOf(needle)`.

This is a thin wrapper but isolates the matching subsystem for testing.

Tests: extend `tests/matching.test.ts`

## Acceptance criteria

- [ ] Returns 0 for needle at start of haystack
- [ ] Returns correct offset for needle in middle
- [ ] Returns -1 for needle not present
- [ ] Empty needle returns 0
- [ ] Empty haystack returns -1 (unless needle is also empty)
- [ ] `bun test tests/matching.test.ts` passes

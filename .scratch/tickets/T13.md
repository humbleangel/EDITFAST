## What to build

Counts additions and deletions from a unified diff string.

File: `src/diff.ts` (extend)

Exports:
- `countChanges(diff: string): { added: number; removed: number }` — walks each line of the diff and counts lines starting with `+` (excluding `+++`) and lines starting with `-` (excluding `---`).

Logic:
```
let added = 0
let removed = 0
for (const line of diff.split("\n")) {
  if (line.startsWith("+") && !line.startsWith("+++")) added++
  else if (line.startsWith("-") && !line.startsWith("---")) removed++
}
return { added, removed }
```

Reference: `tickernelz/opencode-fast-apply` `countChanges`

Tests: extend `tests/diff.test.ts`

## Acceptance criteria

- [ ] Empty diff returns `{ added: 0, removed: 0 }`
- [ ] Diff with one added line returns `{ added: 1, removed: 0 }`
- [ ] Diff with one removed line returns `{ added: 0, removed: 1 }`
- [ ] `---` and `+++` header lines are not counted as additions/removals
- [ ] Mixed diff returns correct counts
- [ ] `bun test tests/diff.test.ts` passes

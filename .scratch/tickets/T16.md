## What to build

Formatter that produces the user-facing success output of a successful edit — file path, change counts, token estimate, and the unified diff.

File: `src/format.ts` (extend)

Exports:
- `formatFastApplyResult(filePath: string, workingDir: string, insertions: number, deletions: number, diffPreview: string, modifiedTokens: number): string`

Logic:
```
const shortPath = shortenPath(filePath, workingDir)
const tokenStr = formatTokenCount(modifiedTokens)
return [
  "✓ Fast Apply complete",
  "",
  `File: ${shortPath}`,
  `Changes: +${insertions} -${deletions} (~${tokenStr} tokens)`,
  "",
  "Unified diff:",
  diffPreview
].join("\n")
```

Reference: `tickernelz/opencode-fast-apply` `formatFastApplyResult`

Tests: extend `tests/format.test.ts`

## Acceptance criteria

- [ ] Output contains `"✓ Fast Apply complete"`
- [ ] Output contains the shortened file path
- [ ] Output contains insertion and deletion counts in `+N -M` format
- [ ] Output contains the token count formatted (e.g. `"~1.5K tokens"`)
- [ ] Output contains `"Unified diff:"` header followed by the diff content
- [ ] `bun test tests/format.test.ts` passes

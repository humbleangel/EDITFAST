## What to build

Formatter that produces the user-facing error output when an edit fails — file path, error message, and a fallback hint.

File: `src/format.ts` (extend)

Exports:
- `formatErrorOutput(error: string, filePath: string, workingDir: string): string`

Logic:
```
const shortPath = shortenPath(filePath, workingDir)
return [
  "✗ Fast Apply failed",
  "",
  `File: ${shortPath}`,
  `Error: ${error}`,
  "",
  "Fallback: Use native 'edit' tool with exact string matching"
].join("\n")
```

Reference: `tickernelz/opencode-fast-apply` `formatErrorOutput`

Tests: extend `tests/format.test.ts`

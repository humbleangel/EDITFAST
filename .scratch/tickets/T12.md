## What to build

Unified diff generator using the `diff` npm package's `createTwoFilesPatch`. Produces a standard unified diff suitable for display.

File: `src/diff.ts`

Exports:
- `generateUnifiedDiff(filepath: string, original: string, modified: string): string` — produces a unified diff. If the diff contains no `@@` hunks, returns the literal string `"No changes detected"` (no diff produced).

Logic:
```
import { createTwoFilesPatch } from "diff"

const patch = createTwoFilesPatch(
  `a/${filepath}`,
  `b/${filepath}`,
  original,
  modified,
  "",
  "",
  { context: 3 }
)
return patch.includes("@@") ? patch : "No changes detected"
```

Reference: `tickernelz/opencode-fast-apply` `generateUnifiedDiff`

Tests: `tests/diff.test.ts`

## Acceptance criteria

- [ ] Returns `"No changes detected"` when original and modified are identical
- [ ] Returns a unified diff with `@@` hunks for added/removed/changed lines
- [ ] Filepaths in the diff are prefixed with `a/` and `b/`
- [ ] Context lines (3 around each hunk) are preserved
- [ ] `bun test tests/diff.test.ts` passes

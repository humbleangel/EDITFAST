## What to build

Shortens an absolute file path to a relative-to-project display path, falling back to absolute when not under the project root.

File: `src/format.ts` (extend)

Exports:
- `shortenPath(filePath: string, workingDir: string): string`

Logic:
- If `filePath === workingDir`, return `"."`
- If `filePath` starts with `workingDir + "/"`, strip `workingDir + "/"` prefix
- Otherwise return the original `filePath`

Reference: `tickernelz/opencode-fast-apply` `shortenPath`

Tests: extend `tests/format.test.ts`

## Acceptance criteria

- [ ] `shortenPath("/proj/src/foo.ts", "/proj")` returns `"src/foo.ts"`
- [ ] `shortenPath("/proj", "/proj")` returns `"."`
- [ ] `shortenPath("/other/foo.ts", "/proj")` returns `"/other/foo.ts"` (unchanged)
- [ ] Empty paths handled
- [ ] `bun test tests/format.test.ts` passes

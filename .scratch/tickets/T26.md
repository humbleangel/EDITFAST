## What to build

Cut a tagged release on the GitHub repo and document it in `CHANGELOG.md`. This is the final "ship" step that signals the tool is usable.

Steps:
1. Verify all previous tickets are merged into `main` and CI is green (T2)
2. Bump version in `package.json` to `0.1.0`
3. Write `CHANGELOG.md` entry: "0.1.0 — Initial release of EDITFAST custom tool"
4. Commit: `chore: release v0.1.0`
5. Create annotated git tag: `git tag -a v0.1.0 -m "EDITFAST v0.1.0"`
6. Push tag: `git push origin v0.1.0`
7. Create GitHub release with `gh release create v0.1.0 --generate-notes`
8. Update Issue #1 with a comment: "Released in v0.1.0 — https://github.com/humbleangel/EDITFAST/releases/tag/v0.1.0"
9. Close Issue #1 as completed

## Acceptance criteria

- [ ] `package.json` version is `0.1.0`
- [ ] `CHANGELOG.md` exists with a `0.1.0` entry
- [ ] GitHub release `v0.1.0` is published
- [ ] Issue #1 is closed with a release link
- [ ] Tag `v0.1.0` exists on origin

## What to build

Parses the Fast Apply API response to extract the merged code from between `<updated-code>...</updated-code>` XML tags.

File: `src/parser.ts`

Exports:
- `extractUpdatedCode(raw: string): string` — finds `<updated-code>` (case-insensitive) opening tag, finds `</updated-code>` closing tag, returns the unescaped content between them. Validates no nested tags. Throws descriptive errors on missing tags or empty content.

Logic:
1. Trim the raw response
2. Match opening tag: `/<updated-code\s*>/i`
3. Find next closing tag after the opening
4. Extract content between tags
5. Verify content is non-empty after trim
6. Unescape XML entities
7. Call `validateNoNestedTags` (from T4) — throws on nested tags
8. Return the cleaned content

Errors to throw:
- "Missing or malformed `<updated-code>` start tag in AI response"
- "Missing or malformed `</updated-code>` end tag in AI response"
- "Empty updated-code block in AI response"
- Whatever `validateNoNestedTags` throws

Tests: `tests/parser.test.ts`

## Acceptance criteria

- [ ] Valid response `..."<updated-code>merged code</updated-code>"...` returns `"merged code"`
- [ ] Whitespace around tags is handled
- [ ] Whitespace inside tags (e.g. `<updated-code >`) is handled
- [ ] Missing start tag throws
- [ ] Missing end tag throws
- [ ] Empty inner content throws
- [ ] Nested `<updated-code>` inside content throws via validateNoNestedTags
- [ ] XML-escaped entities inside are unescaped
- [ ] `bun test tests/parser.test.ts` passes

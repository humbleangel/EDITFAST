## What to build

GitHub Actions CI pipeline running tests and typecheck on every push and PR.

- `.github/workflows/ci.yml` triggered on `push` and `pull_request`
- Uses `oven-sh/setup-bun@v2` action
- Steps: checkout → setup Bun → `bun install` → `bun run typecheck` → `bun test`
- Job named `test`, runs on `ubuntu-latest`

## Acceptance criteria

- [ ] `.github/workflows/ci.yml` exists with trigger on push and PR
- [ ] Pipeline installs Bun, runs typecheck, runs tests
- [ ] Pipeline passes against the T1 scaffold

## What to build

Wire the full execute function: env check → API key check → file readiness check → API call → apply patch → diff → return formatted result. Replaces the T19 stub.

File: `src/tool.ts` (replace the execute body)

Logic flow inside `async execute(args, context)`:
1. Destructure `{ target_filepath, original_code, code_edit }` from `args`; `directory` from `context`
2. Resolve `filepath`: if `target_filepath` starts with `/`, use as-is; else `${directory}/${target_filepath}`
3. **API key check**: if `FAST_APPLY_API_KEY` is empty, return the API-key-missing message string (from T21)
4. **File readiness check**: try `await access(filepath, R_OK | W_OK)` (T21). On error, return file-not-found message.
5. **API call**: `const result = await callFastApply(original_code, code_edit)` (T10)
6. If `!result.success`, format and return the error via `formatErrorOutput(result.error, target_filepath, directory)` (T17)
7. Read the file BEFORE applying changes (for diff baseline): `const originalFileContent = await readFile(filepath, "utf-8")`
8. **Apply patch**: `const applyResult = await applyPartialEdit(filepath, original_code, result.content)` (T11). If `!applyResult.success`, format and return error.
9. **Write file**: `await writeFile(filepath, applyResult.newFileContent, "utf-8")`
10. **Generate diff**: `const diff = generateUnifiedDiff(target_filepath, originalFileContent, applyResult.newFileContent)` (T12)
11. **Count changes**: `const { added, removed } = countChanges(diff)` (T13)
12. **Estimate tokens**: `const modifiedTokens = estimateTokens(diff)` (T14)
13. **Format result**: `return formatFastApplyResult(target_filepath, directory, added, removed, diff, modifiedTokens)` (T16)

Reference: `tickernelz/opencode-fast-apply` `execute` body, lines 380–490 of `index.ts`.

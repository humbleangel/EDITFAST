## What to build

Whitespace normalizer used as a fallback when exact string matching fails in the file patching step.

File: `src/matching.ts`

Exports:
- `normalizeWhitespace(text: string): string` — converts all `\r\n` to `\n`, strips trailing whitespace from every line, then trims leading/trailing whitespace from the whole string.

Logic:
```
text.split('\n').map(line => line.trimEnd()).join('\n').replace(/\r\n/g, '\n').trim()
```

(Reference: `tickernelz/opencode-fast-apply` `normalizeWhitespace`)

Tests: `tests/matching.test.ts`

## Acceptance criteria

- [ ] CRLF line endings are converted to LF
- [ ] Trailing whitespace on each line is removed
- [ ] Leading and trailing whitespace on the whole string is trimmed
- [ ] Empty string returns empty string
- [ ] Round-trip property: `normalizeWhitespace(normalizeWhitespace(x)) === normalizeWhitespace(x)`
- [ ] `bun test tests/matching.test.ts` passes

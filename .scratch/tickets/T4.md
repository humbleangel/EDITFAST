## What to build

Validator that rejects content containing unescaped XML tag-like sequences that could break the Fast Apply prompt's tag structure.

File: `src/xml.ts` (extend, alongside T3)

Exports:
- `validateNoNestedTags(content: string): void` — throws if `content` contains `<updated-code>`, `</updated-code>`, `<code>`, `</code>`, `<update>`, or `</update>` as a substring (after XML unescape). Throws `Error` with descriptive message identifying which tag was detected.

Logic:
1. Unescape the content first (so escaped entities don't trigger false positives)
2. Check for each of the six substrings
3. Throw `Error("<tag> tag detected in content")` on any match

Reference: `tickernelz/opencode-fast-apply` `validateNoNestedTags`

Tests: extend `tests/xml.test.ts`

## Acceptance criteria

- [ ] `validateNoNestedTags("safe content")` does not throw
- [ ] `validateNoNestedTags("<updated-code>x</updated-code>")` throws
- [ ] `validateNoNestedTags("<updated-code>")` does NOT throw (correctly unescaped)
- [ ] Each of `<code>`, `</code>`, `<update>`, `</update>`, `<updated-code>`, `</updated-code>` triggers a throw
- [ ] `bun test tests/xml.test.ts` passes
